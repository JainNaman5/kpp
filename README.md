# 🖨️ Kirti Printing Press (KPP) Website

> **Printing Excellence, All under one roof.**  
> Official website for **Kirti Printing Press** — a premier printing press based in Freeganj, Ujjain (M.P.), delivering high-quality commercial, personal, and industrial printing services.

---

## 🌟 Overview

The **Kirti Printing Press (KPP)** website is a modern, high-performance, and responsive single-page web application designed to showcase the wide range of printing services, in-house industrial machinery, work gallery, and direct quote request features for Kirti Printing Press.

Built with pure Vanilla HTML5, CSS3, and JavaScript, the website features rich visual aesthetics, glassmorphism UI elements, SVG machinery visuals, scroll-triggered animations, interactive stat counters, and fully responsive layouts optimized for all devices.

---

## ✨ Key Features

- **🎨 Premium Visual Aesthetic**: Modern typography, custom color palette, sleek gradients, glassmorphism navigation, and responsive card layouts.
- **⚙️ In-House Machinery Showcase**: Custom interactive SVG graphics highlighting production capabilities including Konica Minolta Digital Color Press, Evolis Primacy PVC ID Printer, Heavy Commercial Copiers, and Large Format Flex & Vinyl Plotters.
- **📦 20+ Service Portfolio**: Clear grid showcase covering services such as Color Printing, Flex Banners, Wedding & Invitation Cards, Trophies & Mementos, PVC ID Cards, Acrylic Name Plates, Bill Books, Lamination, Computerized Seals, and more.
- **🖼️ Work Showcase Gallery**: Visual gallery highlighting real work samples across various categories.
- **📊 Interactive Counter Animations**: Dynamic scroll-triggered counters showcasing business statistics (70+ years experience, 5,000+ happy customers, 50,000+ orders completed).
- **✉️ Direct Quote & Contact Form**: User-friendly message form allowing customers to select specific services and submit inquiries.
- **📱 Fully Mobile Responsive**: Accessible mobile menu drawer, optimized touch targets, and responsive grid layouts for seamless browsing on phones, tablets, and desktops.
- **🔍 SEO & Accessibility Friendly**: Semantic HTML5 markup, Open Graph social tags, accessible ARIA attributes, lazy-loaded images, and high contrast standards.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure, ARIA accessibility attributes, and SEO meta tags.
- **CSS3**: Custom CSS variables (design tokens), Flexbox, CSS Grid layouts, keyframe animations, glassmorphism effects, and custom scrollbar.
- **JavaScript (ES6+)**: Modular script utilizing `IntersectionObserver` for scroll-reveal animations, animated count-up statistics, sticky header toggles, and form validation.

## 🚀 Getting Started

Since this is a lightweight static web project built with vanilla web technologies, no build step or node package installations are required!

### Option 1: Direct File Opening
1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/KPP_website.git
   ```
2. Open `index.html` directly in any web browser (Chrome, Firefox, Edge, Safari).

### Option 2: Local HTTP Server (Recommended)
Running a local web server ensures proper asset resolution and smooth image loading:

- **VS Code**: Use the [Live Server Extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) and click **"Go Live"**.
- **Node.js**:
  ```bash
  npx serve .
  ```
- **Python**:
  ```bash
  python -m http.server 8000
  ```
  Then open `http://localhost:8000` in your browser.
